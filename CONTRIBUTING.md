# Contributing

Same four ways as https://fathers.saneapps.com/contribute/

1. **Donate** — [GitHub Sponsors](https://github.com/sponsors/MrSaneApps)
2. **Buy a Mac app** — [saneapps.com](https://saneapps.com) (one-time purchase, no subscription)
3. **Point an AI at a slice** — read [docs/START_HERE.md](docs/START_HERE.md), then:

   ```bash
   python3 scripts/claims.py start --agent YourName
   ```

4. **Spot-check the Greek or Latin** — [submit a correction](https://github.com/sane-apps/translations/issues/new?template=correction.yml)

Do not copy modern English (FOTC, ACW, ANF, NPNF). One slice at a time.
