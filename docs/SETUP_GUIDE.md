# Fathers Logos Library Setup Guide

Welcome. You bought Word source files, not finished books.
Each book is a normal Word file (.docx). With the steps below
you load them into your Logos Bible software as Personal Books.
You only do this once per book. It takes a few minutes each.

## What you got

- One Word (.docx) file per book (34 in total).
- One cover picture (cover.jpg) for books that have one.
- This guide.

## Before you start

You need the Logos program on a Windows or Mac computer.
The steps below do not work in a web browser or on a phone.
If you do not have Logos yet, install it first and sign in.

## Steps for each book

1. Open the Logos program on your computer.
2. Open the Tools menu, then Utilities, then Personal Books.
3. Choose to add a new book.
4. Type the book title and author name.
5. Add the Word (.docx) file for that book.
6. If the book has a cover.jpg, attach it as the cover picture.
7. Choose Build and wait until it says it is finished.
8. Find the finished book in your Logos Library and open it.
   Bible verses mentioned in the text open in your Bible.

Repeat these steps for every book you want in Logos.

## Good to know

- The Word files use standard Bible references
  (for example Romans 5:12), so links follow whichever
  Bible translation you prefer in Logos.
- A few books quote no Bible verses at all. That is normal
  for those writings. Those books are still complete.
- Menu and button names can look slightly different
  depending on your Logos version. If a name differs,
  pick the closest match. This part is UNVERIFIED across
  versions, so go slowly on your first book.
- Whether books you build also appear on a phone or tablet
  depends on your Logos sync settings. This is UNVERIFIED.
  Build on the computer first, then check your other devices.

If a book fails to build, read the message Logos shows,
fix what it names, and build again.
