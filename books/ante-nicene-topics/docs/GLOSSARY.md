# Project glossary — free will & soteriology (living)

Use these defaults unless a justification receipt overrides for a specific locus.

## Greek

| Lemma | Default English | Notes |
|-------|-----------------|-------|
| προαίρεσις | deliberate choice / choice | Not always “free will” as a system |
| ἐλευθέρα προαίρεσις | free deliberate choice | Justin’s anti-fate phrase |
| αὐτεξούσιον | self-determining power | Prefer this over vague “free will” when the text has it |
| εἱμαρμένη | fate / destiny | Stoic target |
| ἐφʼ ἡμῖν | what is in our power | Aristotelian/Stoic moral vocabulary |
| πίστις | faith / trust | Context decides; don’t force Reformation slogans |
| χάρις | grace / favor | Don’t import later systems |
| ἀπολύτρωσις | redemption / release | |
| ἱλασμός | atoning offering / propitiation | Justify carefully; no automatic “substitutionary atonement” |
| οὐσία | substance / essence | Melito incarnation fragment: δύο οὐσίαι → “two substances,” not “two natures” (φύσεις). Do not follow Grelser’s `duas naturas`. |

## Policy

- Same lemma → same English across authors unless `choices[]` justifies a voice-driven exception (e.g. Tertullian sarcasm).
- Transliterate in captions when the English would smuggle a system.
